## DESCRIPTION

I got tired of dragging images and videos into CapCut one clip at a time, so I
built Media to CapCut Timeline.

Point it at a folder. It reads every image and video, works out the timing, and
generates a real CapCut project that is already registered in your project list.
Images and video can be mixed in the same folder, embedded audio is kept, and you
can add an external audio track on top.

Timing works two ways. Rename your files 0-00.png, 0-09.jpg, 0-18.mp4 and the tool
uses those timestamps exactly. Use ordinary names like 01.png, 02.jpg and it splits
your total duration evenly, aligned to the frame rate.

Other things it does:
- Native 100% scale by default, so nothing is silently cropped or blown up. Flags
  for fill and fit when you want them.
- 16:9, 9:16, and 1:1 canvases, 24 to 60 fps.
- One continuous track, no gaps, no transitions, no effects you did not ask for.
- --dry-run to preview everything without creating a project.
- Refuses to run while CapCut is open, and backs up any project it replaces.
- It does not export an MP4. Review and export in CapCut the way you normally do.

Get it here (free, open source):
https://github.com/banonggang/media-to-capcut-timeline

macOS: double-click the .command file.
Windows: double-click the .bat file. On the first run it offers to install Python,
ffmpeg, and ffprobe for you.
